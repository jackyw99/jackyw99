每週彙整新竹地區成交資訊，提供 Markdown（易讀）與 CSV（可匯入試算表）兩種格式。

## 欄位說明

| 欄位 | 說明 |
| --- | --- |
| 編號 | 該週清單序號 |
| 標題 | 物件銷售標題 |
| 社區 | 社區/建案名稱（無則留空） |
| 地址 | 門牌地址 |
| 行政區 | 由地址解析之行政區 |
| 成交總價(萬) | 成交總價，單位：萬元 |
| 成交單價(萬/坪) | 建坪扣除車位後之概估單價（會因所扣除之車位價格差異而有所不同） |
| 樓層 | 所在樓層 / 總樓層 |
| 屋齡 | 屋齡（年） |
| 建物坪數 | 建物總坪數（含車位） |
| 車位 | 車位情形與含車位坪數 |
